## The Four Process Activities: RetailSync Case Study
Kickoff: For this stage it is missing proper specification, only an hour meeting was held with the developer where they were only given a rough outline of what they needed to do and were handed not written documents.

Development: Development was present during this stage and work well, however validation was severely lacking during this stage as all the developer were working independently with little communication so they were not able to validate if everything was good or matcheded guidelines.

A change of plan: For this specification was completely missing as they didn't change any specifications on how the system would be they just added on the new warehouse which used a different shelving and organizing system so it wouldn't work properly for that warehouse, they should of redesign the system from the ground up instead.

Testing: For this stage evoltuion was lacking as they only did bare basic testing and didn't have the actual users test the application stopping proper fixing and changing of the system.

Go live: Evolution was present in this stage as they had to change and fix the system.

The biggest failure of this project was the kickoff stage as the lack of specification with plans, meetings and briefs led to a cascade of all the problems that would come from the project.

## Researching a Software Failure
Mars Climate Orbiter was a huge software failure that cost NASA $125 million. This software failure occurred due to Lockheed Martin providing thruster acceleration data in imperial units while NASA's navigation team expected and assumed that the thruster acceleration data would be in metric unit. This difference caused the orbiter to be permanently lost during orbital insertion when it flew too close to Mars and burned up in the atmosphere. 
This was a clear lack of specification and validation, the specification for the project should of clarified what unit the data should be in and the validation should of seen Lockheed Martin or NASA identify or ask one another if the units were the correct ones.
